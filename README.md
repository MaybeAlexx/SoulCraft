# SoulCraft Website

Welcome to the SoulCraft website! This project is focused on creating an engaging and visually stunning online presence for the Modded Minecraft Survival gameplay community.

## Project Structure

The project is organized as follows:

```
soulcraft-website
├── src
│   ├── css
│   │   └── main.css        # Custom CSS styles
│   ├── js
│   │   └── app.js         # JavaScript for interactivity and animations
│   └── index.html         # Main HTML document
├── .gitignore              # Files and directories to ignore by Git
├── package.json            # npm configuration file
├── tailwind.config.js      # Tailwind CSS configuration
└── README.md               # Project documentation
```

## Getting Started

To get started with the SoulCraft website, follow these steps:

1. **Clone the Repository**
   ```bash
   git clone <repository-url>
   cd soulcraft-website
   ```

2. **Install Dependencies**
   Make sure you have Node.js installed. Then run:
   ```bash
   npm install
   ```

3. **Build the Project**
   Use the following command to build the project:
   ```bash
   npm run build
   ```

4. **Run the Development Server**
   Start the development server with:
   ```bash
   npm start
   ```

5. **Open in Browser**
   Navigate to `http://localhost:3000` to view the website.

## Features

- **Responsive Design**: The website is fully responsive and optimized for all devices.
- **Tailwind CSS**: Utilizes Tailwind CSS for a modern and clean design.
- **GSAP Animations**: Incorporates GSAP for smooth animations and transitions.
- **Custom Styling**: Additional CSS styles are provided in `src/css/main.css` to enhance the SoulCraft branding.
